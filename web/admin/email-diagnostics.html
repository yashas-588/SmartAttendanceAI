Domain & Key Setup Guide
1. How to get a real Resend API Key
To send emails successfully, you need a valid API Key from Resend:
  1. Register a free account at resend.com.
  2. From the sidebar dashboard, go to API Keys.
  3. Click Create API Key. Give it Full Access permissions.
  4. Copy the key (starts with re_).
  5. Paste this key into your root .env file: 
    RESEND_API_KEY=re_yourRealKeyHere
2. Sandbox Mode vs Production Domain
By default, all new Resend accounts start in Sandbox Mode:
  1. Your default sender email is restricted to onboarding@resend.dev.
  2. Sandbox Restriction: You can ONLY send emails to the single email address used to sign up for your Resend account.
  3. Any emails dispatched to parents, students, or other addresses will be rejected with an API error.
  4. To test locally without domain setups, ensure your test students and parent email addresses in Students matches your own Resend registration address.
3. How to verify your custom domain
To send parent/student notifications to any email address without restrictions:
  1. In your Resend dashboard, go to Domains.
  2. Click Add Domain (e.g. attendance.yourschool.edu).
  3. Add the displayed DKIM, SPF, and MX records in your DNS management provider (GoDaddy, Cloudflare, Namecheap, etc.).
  4. Once status turns to Verified, update your root .env file: 
    EMAIL_FROM=attendance@yourschool.edu
  5. Restart your local server to load changes!
